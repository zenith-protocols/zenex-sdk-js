# @zenith-protocols/zenex-sdk

JavaScript/TypeScript SDK for interacting with the Zenex perpetual trading protocol on Stellar.

## Installation

```bash
npm install @zenith-protocols/zenex-sdk
```

## Usage

```typescript
import { TradingContract, VaultContract, Position, Market } from '@zenith-protocols/zenex-sdk';
```

## Features

- Trading contract interactions (open, close, modify positions)
- Vault contract interactions
- Position and market data reading
- Event parsing
- Full TypeScript support with ESM and CommonJS builds

For detailed documentation, visit the [GitHub repository](https://github.com/zenith-protocols/zenex-sdk-js).
